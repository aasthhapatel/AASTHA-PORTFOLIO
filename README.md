# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/aasthhapatel/AASTHA-PORTFOLIO.git
```

## Navigate to Directory

```bash
cd AASTHA-PORTFOLIO
```

## Run Locally

Open `index.html` in your browser or use VS Code Live Server.

```
Right Click → Open with Live Server
```
